TaskPaw Hub 完整安装包（监控界面＋独立后台服务）

1. 将 TaskPaw Hub.app 拖入 Applications（也支持 ~/Applications）。
2. 双击本安装包中的 Install Hub.command，等待完成；成功后会自动打开监控界面。

无需安装 Python、Node 或另行下载后端。请使用当前登录的 Mac 用户安装，不要使用 sudo。
仅打开 App 不会安装或启动后台服务。若界面显示等待凭据，请完成第 2 步；若安装失败，请保留终端错误。

安装后，后台服务会在用户登录时运行；关闭监控窗口或退出 App 不会停止聚合与通知。
重复运行 Install Hub.command 会复用现有服务管理器；更新时先替换 Applications 中的 App，再运行此入口。
需要查看状态、停止、启动、重启或卸载服务时，双击 Manage Hub Service.command，按提示输入对应操作。
停止或卸载服务会保留配置与历史数据。卸载 App 本身不等于卸载后台服务。
日志位于 ~/Library/Application Support/TaskPaw/HubService/hub.log。

本安装包为 ad-hoc 签名，尚未经 Apple 公证，因此第一次双击 Install Hub.command 时 macOS 会拦截：
请打开「系统设置 → 隐私与安全性」，在下方点「仍要打开」，只需这一次。
放行后，安装入口会清除已安装的 TaskPaw Hub.app 的隔离标记（仅此一个 App，不改系统设置），
后台程序与监控界面不会再次被拦截。清除失败时终端会提示，届时按同样方法放行即可。

不想放行也可以（一次都不弹）：拖入 App 后，打开「终端」粘贴下面一行并回车：
xattr -drs com.apple.quarantine "/Applications/TaskPaw Hub.app" && "/Applications/TaskPaw Hub.app/Contents/MacOS/taskpaw-backend" hub-service install && open "/Applications/TaskPaw Hub.app"
若 App 装在 ~/Applications，请把上面三处 "/Applications/ 换成 "$HOME/Applications/。
